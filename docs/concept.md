# コンセプト

(原則そのものは変えていない。直した所には日付を添えた注を付けた)。細部は [metadata.md](metadata.md)(欄・画面)、
[filename-format.md](filename-format.md)(ファイル名フォーマット)、計画は [roadmap.md](roadmap.md)。

## 目的

**qooViewer・StackNest・ShelfRow が本を管理するためのメタデータを、ファイル名から作る。** qooViewer はそれを EPUB・PDF・CBZ への
書き出しにも使う。利用者は提案を確かめて直し、書き出す。メタデータとして使う情報を抽出・編集するアプリであって、蔵書を管理するアプリではない。

## ターゲットのアプリと、参考にとどめるアプリ

**ターゲットは qooViewer・StackNest・ShelfRow の 3 つだけ。** qooMeta の出力を受け取るアプリで、その欄・フォーマットの書き方・取り込みの
形式は qooMeta の**要件**になる(先方が変われば qooMeta が合わせる)。**qooLibrary はターゲットではない。** 参考で、
「qooLibrary がそうしているから」は何の理由にもならない。ただし参考は無視するという意味ではない: 実際の蔵書と突き合わせて
得られた知識(命名の形、プリセット、実測の結果)が入っているので、**そのまま使わず、1 つずつ qooMeta に要るかを吟味して取り入れる**。
ターゲット以外のアプリは、今後出てきても同じ扱いにする。

| | ターゲット(qooViewer・StackNest・ShelfRow) | 参考(qooLibrary ほか) |
|---|---|---|
| 欄 | **要件**。3 つが管理に使う欄の和集合を持つ | 取り入れない |
| フォーマットの書き方・予約語 | **要件**。同じ書き方にして、型を持ち運べるようにする | 書き方・語は取り入れない |
| プリセット(命名の形の知識) | **出発点**(qooViewer の既定の 12 通り、ShelfRow の既定) | **吟味して取り入れる**(filename-format.md の 5 に、1 項目ずつの判断) |
| 書き出し・取り込みの形式 | **要件**(qooViewer の JSON、Stackroom XML) | 対象にしない |
| 設定の持ち方 | 参考(qooMeta にはライブラリが無いので、合うところだけ) | 取り入れない(ライブラリ単位・フォルダ名の型など) |
| 画面 | 参考。操作の流れだけ(ライブラリを管理する画面は取り入れない) | 取り入れない |
| シリーズと巻(中核) | **寄せない**。書き出すときに先方の形へ変えるだけ | **寄せない** |
| コード・語・データの構造 | 持ってこない | 持ってこない(写してあった `Sources/QooFormat` は 2026-09-20 に捨てた) |

文書やコードで何かの根拠を書くときは、ターゲットの要件か、手元の蔵書の集計か、利用者の判断を挙げる。参考のアプリから取り入れるときは、
「先方にあるから」ではなく、qooMeta に要る理由を書く。

## 原則

1. **本の種類を決め打ちしない。** 商業のコミック(一般向け・成人向け)も同人誌も扱う。どちらであるかを qooMeta が当てず、
   利用者がファイル名の解析のしかた(プリセット)を選ぶ。同人誌の慣習を仕組みに埋め込まない。
   **ただし、1 回の処理で読むのは 1 つの命名の流儀まで**(2026-09-21、利用者の判断)。命名の違う本を 1 度に読ませない
   ―― 種類の違う本をまとめて読む並びは、どの名前にも緩く当たるので、どの解析が合っているかの手がかりを壊す。
   種類が混ざった蔵書は、**種類ごとに分けて処理する**。
   (実装の注、2026-09-21: 解析方法を選ぶ段には「自動」もある。利用者がルールセットごとに書いた語(フォルダ・名前の先頭の語句)で
   本ごとにルールセットを選ぶもので、1 冊はそれぞれ 1 つのルールセットで読む。決まらない本が 1 冊でもあれば選べない。
   filename-format.md「本ごとにルールセットを選ぶ」)
2. **欄は利用先の和集合。** 3 つのアプリがファイル名から取り出し、管理に使う欄だけを持つ(metadata.md の 2)。著者などは、区切りで
   分けた名前の並び(読み取った順)。どう使うかは利用先次第で、欄が 1 つの利用先へは先頭だけを渡す。サークルは発行元ではなく著者の
   並びの先頭。同人誌を、分からないことの多い個人の作者名で管理しない。
3. **名前のどこを何の欄にするか(捨てるかを含む)は、利用者がファイル名フォーマットで決める。** 入手先・版・頒布イベントなどの雑多な
   情報も、`@ignore` で捨てるかキーワードに入れるかをフォーマットで選ぶだけ。別の仕組みは作らない。
4. **タイトルからシリーズ名と巻数を取り出す処理が中核。** 名前の形として定式化できないので、複雑な条件を書ける規則の JSON と、
   ほかの本と見比べる仕組みで扱う。ほかのアプリ(qooLibrary・qooViewer・StackNest)のやり方に寄せて歪ませない。
   フォーマットは欄の位置を読むところまでで、`@series` `@volume` は持たない。
   (実装の注、2026-09-20 に利用者の判断で足した: 名前にシリーズ名・巻数が**はっきり書いてある**形(`@series (@volume) - @author`)に
   限って `@series` `@volume` で読み、利用者が確定した値と同じ扱いで中核へ渡す。タイトルから導く処理そのものは中核のまま。
   filename-format.md の 2)
5. **ライブラリは無い。** 開いたファイルの一覧からメタデータを作り、直して書き出すだけ。設定(型の並び・規則の差分)はアプリの
   設定として 1 組持つ(qooViewer と同じ)。ライブラリ単位・フォルダ単位の設定、シェルフ・評価・未読などは持たない。
6. **フォルダ名は読まない**(3 つのアプリと同じ。本そのものがフォルダのときは、そのフォルダ名を本の名前として読む)。
   (実装の注、2026-09-21: 欄には読まない。段 2 の「自動」だけは、どのルールセットで読むかを選ぶ手がかりとして、フォルダのパスに
   利用者が書いた語が含まれるかを見る)
7. **巻数は 2 つ。** 巻数(ソート用。数)と巻数(表示用。表記)を両方持つ(2026-09-20 の方針変更。metadata.md)。総集編をシリーズに
   含めるかどうかと、含めるときのオフセットは、利用者がアプリの画面で設定する。書き出し先ごとの渡し方は書き出しの対応表で決める。
   (実装の注: オフセットは後に利用者の判断で捨てた。名前に書いていない順番は作らず、総集編の巻数(ソート用)は空か、収録範囲が
   読めたときだけその直後にする(方針 `compilationVolume`)。含めるかどうかは方針 `compilations` で、「抽出の設定」の窓で選ぶ。rules.md)
8. **中核の振る舞いは、すべて規則の JSON で決まる**(2026-09-20、利用者の指示)。タイトルからシリーズ名と巻数(ソート用・表示用とも)を
   導く過程に、コードへ直に書いた語や数を置かない。語の一覧・パラメータ・方針・条件の有効無効は、既定値の JSON にあり、
   利用者が差分で足す・外す・変えられる(rules.md)。画面で変えられる設定(総集編の切り替えなど。オフセットは後に捨てた)も、規則の差分として持つ。
   ハードコードしてよいのは、条件や読み手の**種類の実装**(「XXXX の場合」の判定そのもの)だけで、どの語・どの数で効かせるかは JSON に置く。
   新しい種類が要るときは、規則の形式に種類を足す(rules-format-design.md の `engineLevel`)。
9. **道具の側で偏りをかけない。** 取り違えや偶然の一致を、語の一覧や場合分けの例外で先回りして防がない。読んだ結果をそのまま
   見せ(一覧・並べ替え・絞り込み)、利用者がまとめて直せるようにし、方針は設定で選べるようにする。
10. **ターゲットと参考を混ぜない**(上の表)。ターゲットの 3 つに合わせるのは欄・フォーマットの書き方・受け渡しの形式まで。
   qooLibrary などは参考で、コードも語も構造も持ってこない。

## これまでの実装からの見直しで分かったずれ

| これまで | ずれ |
|---|---|
| ファイル名の読み方は同人誌のプリセット 1 組と「括弧の位置だけで読む」予備 | 商業の本などの命名を読めない。末尾の括弧の意味を決め打ちしていた |
| 欄が同人誌の言葉(サークル・ネタ・イベント・本の種別)。版・入手経路に専用の欄 | 利用先の欄と合っていない。雑多な情報に大きすぎる仕組み |
| 本の種別の語の一覧を前提にしていた | 種別の無い蔵書・書き方が違う蔵書を考えていない |
| 画面の中心がシリーズの一覧と、意味の薄い絞り込み | 本ごとのメタデータを見つけて直す流れになっていない |

このため、**中核(シリーズと巻)は移し、ほかは作り直す**(roadmap.md)。
